## Как запустить любую работу

Нужен Python 3.12 или новее.

```
cd cp10-flask-final
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Дальше — команды из README выбранной папки. Базы данных в репозиторий не входят: Flask-приложения заполняются командой `seed`, Django-приложения — миграциями.
